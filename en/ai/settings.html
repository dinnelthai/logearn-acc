The Basic Settings Page

After importing, all parameters are already carried over — this page is mainly for checking and fine-tuning. The two things you'll typically actually change are the active time window and the buy order amount.

1Top Half · Trigger Method

The four tabs at the top are 基本设置 (Basic Settings), 策略逻辑 (Strategy Logic), 实时日志 (Live Logs), and 清理 (Cleanup); the top right has 保存策略 (Save Strategy) and AI 生成代码 (AI-Generate Code). You must click save after making changes.

2Bottom Half · Trading and Tiers

From the active time window downward: the Auto Trading toggle, order method, amount, wallet, take-profit/stop-loss, and win-rate distribution tiers.

Strategy Trigger Method (Choose One of Three)

This is the single most important choice on the page — it determines which data this strategy can use.

Method How It Triggers / What Data It Can Use
Signal-Triggered Driven by signals already on the platform — good for adding one more filter layer on top of a signal. Can use all data: logearn holders kline indicator chip_analysis. All three official strategies use this method.
Token Live-Stream-Triggered Covers every token's every-second changes across the whole chain — good for "chain scanning" strategies (new tokens / just graduated / market cap just crossed a threshold). Can only use logearn and signals data — no access to holders or chip analysis.
Strategy-Triggered Subscribes to the pool of matched tokens produced by one or more "Token Live Stream" strategies, then re-checks tokens in that pool using richer data. Can use all data — effectively, the live stream does a rough first pass, and this does the fine filtering.

Trading Parameters

Parameter Description
Enable Auto Trading Automatically buys on a hit. Unchecked, it only produces a strategy signal without placing an order. Turn this off if you want to observe for a while first.
Allow Multiple Concurrent Positions Unchecked: no matter how many strategies you have running at once, the same token is bought only once, unless that position is sold and a new signal comes in. Checked: this check is skipped, allowing you to add to the same token's position repeatedly.
Buy Only on First Match Checked: this token is bought only once — after selling, even if this strategy matches it again, it won't be bought again. Unchecked: only checks whether you currently hold a position — no buy if you're holding, and buys again if you're not holding and a new signal comes in.
Buy Order Method 市价买入 (Market Buy): buys at market price the instant it hits. 网格挂单 (Grid Order): doesn't buy immediately, and instead lays down limit orders in batches — configuration is in the next section. Once switched to Grid Order, the "Buy Order Amount" above no longer applies; the amount is instead determined by the grid template.
Buy Order Amount How much to buy each time under Market Buy, followed by the quote currency: USDC / USD1 / USDT / SOL. The screenshot shows 10 SOL.
Trading Wallet Which wallet places the order — the balance is shown on the right. Always double-check this after importing someone else's strategy — the wallet and amount are tied to your own account.
Take-Profit / Stop-Loss Once checked, pick a take-profit/stop-loss rule set from the dropdown (the screenshot shows "1.5-Stage Strategy Take-Profit/Stop-Loss"); click the gear icon next to it to edit the specific values.
Win-Rate Distribution Tiers Customize the five gain tiers (in %) shown on the strategy card, which track what percentage of matched tokens reached each gain level. Blank tiers are ignored; if all are left blank, the default 30 / 100 / 300 / 500 / 1000 is used. There's a 恢复默认 (Reset to Default) button next to it.

Grid Orders

Switching "Buy Order Method" to 网格挂单 (Grid Order) reveals an extra block of settings below, and the "Buy Order Amount" field above changes to "Trading Currency."

What Grid Order looks like expanded. The red text above marks the behavior when "Buy Only on First Match" is unchecked — no buy while holding, buys when there's no position and a signal arrives.

Parameter Description
How Orders Are Placed Instead of buying at market price immediately on a hit, it places batches of limit buy orders across the drawdown range from the reference price, according to the template. Selling still follows the take-profit/stop-loss configured above.
Trading Currency USDC / USD1 / USDT / SOL. The amount configured in the template (in USD or native token) is converted to this currency at the current exchange rate before the order is placed.
Reference Price 当前市值 (Current Market Cap) or 最高市值 (Highest Market Cap). The drawdown range is calculated relative to this price — choosing Highest Market Cap means orders are laid down from the historical high, so the same range places orders lower.
Drawdown Range Two percentages; the screenshot shows -0% to -50%, meaning grid levels are laid out across the range from the reference price down to half of it.
Grid Template Determines how much each order buys and how many levels are laid out; the screenshot shows 买$10平分网格挂单(5 格) (Buy $10, split evenly across a grid order (5 levels)). The per-order buy amount comes from the template, not the "Buy Order Amount" field above — click the gear icon next to it to change the template's amount.
Weighing Grid Orders vs. Market Buy. Market Buy takes the fill the moment a signal arrives, prioritizing speed; Grid Orders wait for a pullback and buy in batches, prioritizing cost basis — but the trade-off is that if the token just rips upward, none of the grid levels fill. Signals like Post-pullback Rebound are already about buying dips, so grid pairs well with them; something like Early Pick that needs to move fast can end up empty-handed with a grid.
Check two things first after importing. First, the active time window — someone else's exported strategy may run on their schedule, so reset it to your own timezone and monitoring hours. Second, the trading wallet and buy order amount — these are tied to your own account, and skipping this check while enabling auto trading means trading on default values.
